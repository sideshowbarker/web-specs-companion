Web Specs Companion

A browser extension for reading web specs and finding the groups and people behind them

On a spec from W3C, WHATWG, TC39, the IETF, Khronos, or elsewhere, it shows what’s known of the spec’s maturity, versions, repository and issue tracker, tests, and the group responsible for it. For a W3C spec, that includes the editor’s draft and TR versions, and the group’s chairs, team contacts, and charter end date.

Web Specs Companion is a personal project. It isn’t affiliated with or endorsed by W3C.

Install it Free and open source, and it collects nothing about you.

At TPAC 2026 in Dublin, 26–30 October, it shows what’s in session now and next, and when each group meets.

What it shows

And also

  • Search for specs, groups, Web IDL names, and terms: Type spec and a space in the address bar (in Chrome, Edge, and Firefox).
  • A check of the spec’s links to other specs, for anchors that no longer exist.
  • A summary of the spec’s place in the web platform.
  • It works offline, from data it bundles and refreshes every few hours.

Install it

The latest release is version {{version}}. It needs Chrome or Edge 148 or later, Firefox 128 or later, or Safari 26 or later, on a desktop computer.

Web Specs Companion runs in desktop browsers, so open this page on your computer to install it.

Chrome, Edge, and other Chromium-based browsers

Add to Chrome

The Chrome Web Store installs it, and keeps it up to date. Edge, Brave, and other Chromium-based browsers install it from there too — Edge first asks you to allow extensions from other stores.

Web Specs Companion is waiting for review in the Chrome Web Store. Until it’s there, load it from the release zip:

  1. Download the zip, and unzip it into a folder it can stay in — the browser loads the extension from that folder every time it starts.
  2. Open chrome://extensions (edge://extensions in Edge, brave://extensions in Brave).
  3. Turn on Developer mode.
  4. Click Load unpacked, and select the unzipped folder.

To update it, unzip a newer release into the same folder, and click the reload button on the extension’s card.

Firefox

Add to Firefox

Firefox Add-ons installs it, and keeps it up to date.

Web Specs Companion is waiting for review on Firefox Add-ons. Until it’s there, Firefox can run it as a temporary add-on, which Firefox removes when it quits:

  1. Download the zip.
  2. Open about:debugging, and click This Firefox.
  3. Click Load Temporary Add-on…, and select the zip.

Add it again the same way after Firefox restarts.

Safari

Safari 26 or later can run Web Specs Companion as a temporary extension, which Safari removes when it quits and after 24 hours — so add it again whenever it’s gone.

Once, choose Safari → Settings…, select Advanced, and turn on Show features for web developers. Then, each time:

  1. Download the zip, if you don’t have it already.
  2. In Safari → Settings…, select Developer, click Add Temporary Extension…, and select the zip (or the folder, if Safari unzipped it). Authenticate if Safari asks to allow unsigned extensions.
  3. Click the extension’s toolbar button, which shows a warning sign until you allow it, and allow it on every website.

Safari has no address-bar keywords or side panels for extensions, so the spec search and the side panel aren’t there.

Once it’s installed, pin Web Specs Companion to the toolbar from the browser’s extensions menu, and click its button on any spec, W3C repo on GitHub, or w3.org group page.
