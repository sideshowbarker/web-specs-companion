# Privacy

Web Specs Companion doesn’t collect, store, or transmit any personal data.

- It reads the address and content of the page in the current tab, in the browser, to recognize specs, W3C repositories,
  and w3.org group pages. That information stays in the browser.
- To show information about a spec or a group, it fetches public data from api.w3.org, www.w3.org, w3c.github.io,
  sideshowbarker.net, and respec.org. Those requests carry the name of the spec, group, or term being looked up, and
  nothing about the user.
- It stores a cache of that public data, two settings (whether to show definition usage in pages, and whether to show a
  Comment button beside selected text), and the comments of any review you write, in the browser’s extension storage.
- A review’s comments leave the browser only when you copy them, or file them: Filing opens GitHub’s new-issue page, in
  a new tab, with the comment in its address.
- It has no analytics and no tracking.
